# 毕业论文管理系统

## 项目概述

这是一个面向学校、教师和学生的毕业论文管理系统。系统把论文提交、附件上传、教师审阅、消息通知、批量下载和后台管理放在同一个平台里，帮助学校把论文管理流程变得更清晰、更省事。

从使用者角度看：

- 学生可以在系统里上传论文和附件，查看教师批注，跟进修改状态。
- 教师可以集中查看所带班级的论文，进行审阅、反馈、消息沟通和批量下载。
- 管理员可以统一维护用户、群组、公告和院校信息，保证系统正常运转。

## 技术栈

- `uni-app`：用于构建多端页面，适合同时适配 Web、App 等场景。
- `Vue`：页面组件和交互逻辑的基础框架。
- `JavaScript`：页面业务逻辑、状态管理和接口调用主要使用的语言。
- `HTML / CSS`：负责页面结构和视觉样式。
- `docx-preview`：用于在线预览 Word 论文文档。
- `uni.request` 接口封装：统一处理登录、请求和错误提示，方便对接后端服务。
- `Material Symbols` 图标字体：用于页面中的功能图标和操作入口。

## 配置说明

### 1. 安装 Node.js

项目使用 `npm` 管理依赖，首先需要在电脑上安装 Node.js。建议安装较新的 LTS 稳定版本。

常见安装方式：

- Windows、macOS：到 Node.js 官网下载安装包，安装完成后重启终端。
- Linux：可以使用系统包管理器安装，也可以从 Node.js 官网下载对应版本。

安装完成后，可以在终端检查是否成功：

```bash
node -v
npm -v
```

如果能看到版本号，说明环境已经准备好。

### 2. 安装项目依赖

进入项目根目录后执行：

```bash
npm install
```

这个命令会把项目运行需要的依赖下载安装到本地。

### 3. 启动开发环境

如果项目已经配置了开发脚本，可以执行：

```bash
npm run dev
```

如果你使用的是 uni-app 常见开发方式，也可以通过 HBuilderX 打开项目并直接运行到浏览器、小程序或真机调试。

### 4. 连接后端服务

项目默认通过接口配置文件对接后端服务。上线前通常只需要确认后端地址正确，前端就可以正常访问登录、论文管理和附件上传等功能。

## 项目功能

### 1. 学生端

- 登录系统并找回密码。
- 进入学生工作台，查看自己的论文状态概览。
- 上传论文和附件。
- 查看论文详情与在线预览内容。
- 查看教师批注、修改建议和论文定稿状态。
- 查看系统公告和截止时间提醒。
- 进入附件列表，查看、下载或删除已上传附件。
- 在个人中心修改密码、完善资料和退出登录。

### 2. 教师端

- 登录后按班级查看学生论文。
- 按论文状态筛选，如待审阅、待修改、已定稿、未上传等。
- 查看学生论文内容并进行审阅反馈。
- 通过消息中心和学生进行沟通。
- 设置论文提交截止日期。
- 批量下载论文资料，方便集中归档和检查。
- 在个人中心维护个人信息、修改密码和退出登录。

### 3. 管理员端

- 统一进入系统管理后台。
- 管理群组信息，维护教师和学生之间的归属关系。
- 批量导入师生关系，减少人工录入工作。
- 管理用户权限，区分不同角色的使用范围。
- 发布和维护系统公告。
- 查看群组关系，方便掌握整体组织结构。
- 维护院校信息，保证基础资料准确。
- 在管理员个人中心查看信息、修改密码和退出登录。

## 页面说明

系统首页是登录页，支持学生、教师、管理员三种身份切换。除此之外，还提供忘记密码页面，以及分别面向学生、教师和管理员的业务页面，方便不同角色按自己的工作流程使用系统。

## 适用场景

- 高校毕业论文管理
- 指导教师论文审阅与反馈
- 学生论文提交与附件管理
- 学校层面的论文流程统一管理
